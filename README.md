# GrowthGrid

GrowthGrid is a small habit tracker built as a single self-contained HTML file. Add a habit, then mark it done on any day of the current week by clicking its cell in the grid. Each habit shows its current streak, and the header keeps a running count of habits tracked, how many are done today, and the best streak among them.

Everything is stored in the browser's local storage, so your data stays on whichever device you use it from and nothing is sent anywhere. There are no external libraries or network requests involved, so the file works the same whether you open it locally or host it through GitHub Pages.
